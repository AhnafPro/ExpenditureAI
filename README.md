### A custom algorithm-based web app for monthly budget tracking, finding alternatives, and cost-cutting, designed specifically for students' spending.
##### The algorithms logics are totally custom; therefore, nothing was copied or generated by AI. The flowchart containing the logic of the algorithm was first prepared using Figma and draw.io and later integrated into the site using JS.
